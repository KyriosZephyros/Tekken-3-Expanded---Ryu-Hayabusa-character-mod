# Tekken-3-Expanded---Ryu-Hayabusa-character-mod (still in work)
So this project adds a new character for tekken 3 expanded mod with it's model rebuilt for the tekken 3 engine, based on Ryu hayabusa's DOA2 1st costume.
it took a lot of time to extract the character model, put it on blender and with help of ai rebuild it to fit the game, the character has his own voicefiles
has the announcer voice naming him, his own portrait and name label

Instructions :
So with the files, you need to go to /build-release /mods /ttt1 ...  and then drag the files to the folder and replace
